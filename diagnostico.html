Comprobemos la conexión.

Esta página solo consulta los servicios públicos de Supabase. No modifica productos, contraseñas ni configuraciones. Úsala si el catálogo o el panel dejan de cargar.

Estado de la conexión

Haz clic para consultar el estado de la API y el acceso público al catálogo.

Si la conexión falla, haz lo siguiente:
  1. Entra al panel de Supabase y abre tu proyecto ATLE.
  2. Si aparece Paused o Resume project, reactiva el proyecto y espera a que aparezca Healthy.
  3. Si ya dice Healthy, compara su Project URL con la de configuracion.js. Usa exclusivamente tu publishable key o anon, nunca una clave secreta.
  4. Repite esta comprobación. Si muestra un error 401/403, revisa la clave y las políticas RLS. Si dice «no responde», revisa el estado del proyecto y la conexión a Internet.
Un error de red, por sí solo, no demuestra que la contraseña o la clave sean incorrectas. No vuelvas a ejecutar el SQL de instalación sobre un proyecto que ya contiene productos.
